# `@thegreataxios/webmcp-examples-theme`

Shared visual system for webmcp example apps.

## Usage

```ts
import "@thegreataxios/webmcp-examples-theme/theme.css";
import "@thegreataxios/webmcp-examples-theme/motion.css";
```

## Tokens

- **Fonts:** Syne (display) + Plus Jakarta Sans (body)
- **Accent:** deep teal on cool mist surfaces
- **Layout:** `.wm-page`, `.wm-hero`, `.wm-brand`, `.wm-section`, `.wm-panel`
- **Motion:** `.wm-animate-in`, dialog enter, soft status pulse

Import the CSS from example Vite apps; no runtime JS required.
