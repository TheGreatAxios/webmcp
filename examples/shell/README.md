# Shell example

Blank themed shell for the webmcp examples visual system.

## Run

From the monorepo root:

```bash
bun install
cd examples/shell
bun run dev
```

Opens on **http://localhost:43109**.

## What it demos

- Shared `@thegreataxios/webmcp-examples-theme` tokens and layout
- Hero composition with brand-first hierarchy
- Entrance motions (respects `prefers-reduced-motion`)

No WebMCP tools are registered in this example.
