# @thegreataxios/webmcp

Umbrella package for the **webmcp** family. Re-exports core and framework/bridge subpaths:

| Import | Package |
|---|---|
| `@thegreataxios/webmcp` | `@thegreataxios/webmcp-core` |
| `@thegreataxios/webmcp/elements` | `@thegreataxios/webmcp-elements` |
| `@thegreataxios/webmcp/react` | `@thegreataxios/webmcp-react` |
| `@thegreataxios/webmcp/svelte` | `@thegreataxios/webmcp-svelte` |
| `@thegreataxios/webmcp/vue` | `@thegreataxios/webmcp-vue` |
| `@thegreataxios/webmcp/bridge` | `@thegreataxios/webmcp-bridge` |

For most apps, install only the packages you need (`@thegreataxios/webmcp-core` + your framework adapter).

See the [repository README](https://github.com/TheGreatAxios/webmcp).
