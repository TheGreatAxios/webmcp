# @thegreataxios/webmcp

Umbrella entry for the **webmcp** package family. Re-exports:

| Import | Package |
|--------|---------|
| `@thegreataxios/webmcp` | `@thegreataxios/webmcp-core` |
| `@thegreataxios/webmcp/react` | `@thegreataxios/webmcp-react` |
| `@thegreataxios/webmcp/bridge` | `@thegreataxios/webmcp-bridge` |

For most apps, install the specific package you need (`webmcp-core`, `webmcp-react`, or `webmcp-bridge`) instead of this umbrella.

See the [repository README](https://github.com/thegreataxios/webmcp).
